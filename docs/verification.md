# 当前验证范围

当前布置版在 macOS arm64 的原工具箱内嵌模块，用实际系统鼠标事件检查四尺寸布局、道具缩放及边界、缩放后移动、镜像、桌面附着、大幅上下移动和边缘找回、前后层次、整组取消／保存与新进程重开。两处指定遮挡为吊灯与盆栽、茶几及桌面摆件与完整椅子／猫头鹰组。

`npm test` 检查计时、存储失败与恢复、正常／试用独立、旧存档原字节备份、尺寸接点及镜像范围、原子保存和陈旧修改保护等逻辑。

`verify:ui` 和后续 `verify:reopen` 使用新隔离数据及离屏 Electron 检查独立入口、开始／暂停、双视图共享同一次计时及进程恢复。它们不是用户桌面操作或真实专注记录。

README 的 GIF 来自本项目自身 UI 的隔离示例；静态主图明确标为概念示意。用户最终审美判断、真实系统睡眠、长期后台运行和真实 APP 采集不属于本轮已通过结论；不声称整个产品所有历史目标都已验收。
