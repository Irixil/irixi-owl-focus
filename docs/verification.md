# 当前版本的检查范围

2026-10-05 在 macOS arm64 对共享界面候选完成真实隔离工具箱内嵌与可见独立入口检查，并按原正常构建流程更新本机工具箱。独立源码仍以 npm 启动，不提供签名安装包。

实际窗口检查覆盖：

- 原迷你、小、中、大尺寸循环；空任务开始后返回房间，提示与主按钮的间距分别为12、10、8、5px，文字相交为0，按钮真实可点击。
- 物理短点猫头鹰、近头区注视和平滑回正；物理长按交换与还原模块，Escape取消；长按不触发轻点回应，计时继续，暂停后不累加。
- 可见独立入口恢复和暂停内嵌的同一轮；返回内嵌保留进度；正常外部窗口激活后收起，再次展开保留暂停状态。
- 凳子与椅子使用实际原图，接触阴影按原座位alpha位置固定，角色没有整图下移；减少动效关闭轻点和注视动画。

座椅解锁使用受控经过时间，仅用于显示装备；Escape通过原生输入发送。其余上述鼠标操作使用真实桌面事件。参考图片已在本机查看，仅用于背景方向，不进入公开素材。所有新验收截图和诊断日志只留本机；README保留上一版历史示例图。

第一次检查误把原工具箱置顶层级视作普通窗口层级；其后修正了按DOM顺序判断布局的错误，布局实际使用CSS排序。长按检查等待原布局动画结束并让鼠标移动送达后，通过完整路径。安装后第一次自建外部辅助窗口没有正常激活，不能证明收起；换成正常激活的自建窗口后，实际安装的收起/重开通过。没有删除或关闭产品的失焦处理来取得通过。

本机更新仅替换共享界面和两个资源清单，主程序、其他模块与原生组件保持原样。旧应用、旧界面和真实存档有本地回滚备份；新包使用原固定本机签名，实际启动/收起/重开后真实专注存档保持原字节。没有开启真实APP记录或新增系统权限。
