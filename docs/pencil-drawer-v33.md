# 铅笔房间与收藏抽屉

这次修改针对“先看一件再存一件，难以在房间中搭配”的问题。右上角收藏箱图标可直接进入收藏；灯、毯、座椅、盆栽与配饰使用图形分类。点击道具时，当前主房间同步显示，不另外打开第二个预览房间。跨分类的试摆保留在本窗口内存；取消、关闭或 Escape 恢复当前已保存的整组装扮。点“放好”才请求一次整组保存。

保存会在可信主进程检查所有分类、使用权限与当前装扮版本；某件道具不允许使用，整组都不会部分写入。另一个窗口先保存后，旧试摆会恢复到最新装扮，避免覆盖。主房间或缩略图故障、保存故障均不视为保存成功。

全道具体验仍只保存独立的测试装扮与开关；真实成长、永久收藏、普通装扮不随试摆改变。正常有效专注跨过获得门槛时，显示真实道具图与名称，可点“去试摆”；不自动替换装扮。没有新增货币、概率、付费或 APP 活动奖励。
